# Changelog

All notable changes to Mint Device Screensaver are documented here.

## 0.10.1 (In Development)

### Documentation
- Added project screenshots.
- Improved README presentation.
- Documented the graphical settings application.

## 0.10.0

### Added
- Added graphical settings application.
- Added persistent user configuration.
- Added animation speed control.
- Added background colour selection.
- Added reset-to-default settings.

### Improved
- Improved user customization workflow.
- Added dynamic colour transition behaviour.

## 0.9.1

### Improved
- Improved local Debian package installation workflow.
- Avoided confusing apt sandbox warnings.
- Updated installation documentation.
- Cleaned generated Debian package artifacts.

## 0.9.0

### Added
- Added standalone application installer.
- Added standalone uninstall utility.
- Added README screenshots and documentation improvements.
- Improved release packaging workflow.

## 0.1.2

### Improved
- Improved standalone application experience.
- Added command-line help support.
- Improved desktop entry metadata.
- Verified Cinnamon lock and unlock workflow.

## 0.1.0

### Added
- Initial release.
- GTK and Clutter based animated screensaver.
- Cinnamon integration.
- SVG and PNG application icons.
- Desktop menu entry and launcher.
